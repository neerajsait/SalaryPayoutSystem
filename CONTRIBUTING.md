# Contributing to Salary Payout System

First off, thank you for considering contributing to the Salary Payout System! It's people like you that make open source such a great community to learn, inspire, and create.

## Getting Started

1.  **Fork the repository** on GitHub.
2.  **Clone your fork** locally.
3.  **Create a new branch** for your feature or bugfix (`git checkout -b feature/amazing-feature`).

## Local Development

The system is built as a set of Spring Boot microservices. 

1. Ensure you have **Java 21**, **Maven**, and **MySQL** installed.
2. Create your `.env` files for external secrets like Stripe API keys.
3. Run the services locally (FrontendService, EmployeeService, PaymentService).

## Submitting a Pull Request

1.  Commit your changes (`git commit -m 'Add some amazing feature'`).
2.  Push to the branch (`git push origin feature/amazing-feature`).
3.  Open a Pull Request against the `main` branch.

Please ensure your code follows the existing style, and try to include tests where applicable.

## Reporting Bugs

If you find a bug, please create an issue with detailed steps to reproduce it.
